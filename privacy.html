Privacy Policy

North Addon Bot · last updated: October 2026

Who this applies to

North Addon Bot is a private tool used by the North Addon Team. It is used with a single Google account that belongs to the team. It does not collect information from visitors, members of the Discord server, or any other person, and it has no sign-up.

What Google data the app accesses

The app uses the Google Drive permission drive.file. This lets it access only the files and folders that the app created itself (a folder named "North Addon" and the addon files inside it). It cannot access any other file in the Google Drive.

How it is used

The app uploads addon files to that folder and enables "anyone with the link" sharing on those files, so the download link can be posted in the North Addon Discord server. Nothing else is done with the data.

Storage and sharing

The app stores a login key for the team's Google account on the computer that runs the bot, so it can keep uploading. This key is never shared. The app does not sell, share, transfer or publish Google user data to anyone, does not use it for advertising, and does not allow people to read it. The only content that becomes public is the addon files that the team chooses to upload for download.

Google API Services User Data Policy

North Addon Bot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

Files can be deleted at any time by deleting the "North Addon" folder in Google Drive. Access for the app can be removed at myaccount.google.com/permissions.
